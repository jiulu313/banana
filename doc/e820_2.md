### 1. E820 是什么

在 BIOS 实模式下，可以调用：

``` 
int 0x15
```

并设置 ：
```
EAX = 0xE820
EDX = 0x534D4150   ; "SMAP"
ECX = 24
ES:DI = 保存结果的位置
```

BIOS 每次返回一条内存区域信息，例如：

```
base       = 0x00100000
length     = 0x07EE0000
type       = 1
```

意思是：

>  从 0x00100000 开始，有这么长的一片可用 RAM。

我们需要不断调用 BIOS，因为一次只返回一个 entry。

第一次：

```
EBX = 0
```
BIOS 返回第一条，同时修改 EBX。
第二次再把这个 EBX 原样传回去。
一直到：

```
EBX = 0
```
说明内存地图遍历结束。

流程：

```
EBX = 0
  ↓
INT 15h E820
  ↓
entry 0
  ↓
EBX = continuation value
  ↓
INT 15h E820
  ↓
entry 1
  ↓
...
  ↓
EBX = 0
  ↓
结束
```


### 2. 我们规定一块内存保存地图
```
E820_COUNT  equ 0x4FF0
E820_BUFFER equ 0x5000
```

布局：

```
0x4FF0
┌────────────────────┐
│ entry count        │ 4 bytes
└────────────────────┘

0x5000
┌────────────────────┐
│ E820 entry 0       │ 24 bytes
├────────────────────┤
│ E820 entry 1       │ 24 bytes
├────────────────────┤
│ E820 entry 2       │
├────────────────────┤
│ ...                │
└────────────────────┘
```

每个 entry：

```
offset  size

0       8     base
8       8     length
16      4     type
20      4     ACPI extended attributes
```



### 3. 修改 stage2.asm
在顶部增加：

```
E820_COUNT       equ 0x4FF0
E820_BUFFER      equ 0x5000
E820_ENTRY_SIZE  equ 24
E820_MAX_ENTRIES equ 128
```


然后在 start 一开始，保存启动盘号以后，调用：
```
start:
    ; 确保数据段为 0
    xor ax, ax
    mov ds, ax
    mov es, ax

    ; 保存启动磁盘
    mov [boot_drive], dl

    ; 获取 BIOS 内存地图
    call detect_memory

    ; 后面继续加载 kernel
```
