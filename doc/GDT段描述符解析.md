
### GDT描述符作用
GDT 描述符是 x86 保护模式下每个内存段的 8 字节属性表项，用来告诉 CPU：这个段从哪里开始、有多大、能不能执行/读写、特权级是多少。


> GDT 里的每一个段描述符
>
> 本质上是在描述一个“段”：它从哪里开始、能有多大、是什么类型、
>
> 什么权限、按 16 位还是 32 位工作。


### 结构大致是：
```
+--------+--------+--------+--------+--------+--------+--------+--------+
| Base   | Flags  |Access  | Base   | Base   | Limit  | Limit  | Base   |
|31..24  |+Lim    |        |23..16  |15..8   |15..8   |7..0    |7..0    |
+--------+--------+--------+--------+--------+--------+--------+--------+


```


### 每个段描述符是8个字节，也就是64位


按 Intel 手册常见位序，一个代码/数据段描述符长 64 位：

| 位 | 字段 | 含义 |
|---|---|---|
| 0–15 | Limit 15:0 | 段限长低 16 位 |
| 16–39 | Base 0:23 | 段基址低 24 位 |
| 40–43 | Type | 段类型子字段 |
| 44 | S | 1=代码/数据段；0=系统段 |
| 45–46 | DPL | 描述符特权级，0–3 |
| 47 | P | 段是否存在于内存 |
| 48–51 | Limit 19:16 | 段限长高 4 位 |
| 52 | AVL | 软件可用位 |
| 53 | L | 64 位代码段标志 |
| 54 | D/B | 操作数/地址/栈大小 |
| 55 | G | 粒度位 |
| 56–63 | Base 24:31 | 段基址高 8 位 |


**简单描述：**
```


0-15    段限长16位

16-39   段基址低24位

40-43   段类型，type

44      1：代码/数据段，0：系统段

45-46   DPL，描述符特权等级，0-3

47      P,段是否存在内存中

48-51   段限长高4位

52      AVL:软件可用位

53      L:64位代码码标志

54      D/B:操作数/地址/栈大小

55      G:粒度位

56-63   段基址高8位
```
